## Daily practice with Claude
Open Claude Code in this folder and type:
- **`start practice`** → today's topic from [progress.md](progress.md), one question at a time, with a score and feedback
- **`practice node`** / **`practice sql`** … → any topic
- **`mock`** → a full interview round · **`rapid fire`** → 15 quick questions
- **`hint`** / **`skip`** / **`explain <topic>`** during a session
